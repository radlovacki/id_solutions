# T5577

## Memory Map

363-bit EEPROM arranged in 11 blocks of 33 bits each.

Memory is subdivided into two page areas:

* Page 0 contains eight blocks
* Page 1 contains three blocks

| Page   | Bit 0 | Bit 1 ... Bit 32                    | Block |
| :----: | :---: | :---------------------------------: | :---: |
| 1      | **L**     | Analog front end option set-up      | 3     | 
| 1      | **1**     | Traceability data                   | 2     |
| 1      | 1     | Traceability data                   | 1     |
| 1      | L     | Page 0 configuration data           | 0     |
| 0      | L     | User data or password               | 7     |
| 0      | L     | User data                           | 6     |
| 0      | L     | User data                           | 5     |
| 0      | L     | User data                           | 4     |
| 0      | L     | User data                           | 3     |
| 0      | L     | User data                           | 2     |
| 0      | L     | User data                           | 1     |
| 0      | L     | Configuration data                  | 0     |
